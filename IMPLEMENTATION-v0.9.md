# Folio 0.9 implementation

14 October 2026. Optional voice data, authentic previews, continuous guided paint and reading information.

## Voice packs and previews

The core APK retains the native runtime and license/identity metadata but excludes Kokoro and Supertonic weights, voice tensors and phonemizer data. A generated filtered asset directory enforces the exclusion for debug and release. A development-only debug property can include the existing files for native test fixtures and sample generation; it never affects release packaging.

VoicePackCatalog parses the APK-pinned pack/voice/language/sample registry with bounded sizes, safe paths and exact GitHub release URLs. VoicePackWorker uses persistent WorkManager jobs, connected-network constraints, foreground progress/cancellation, bounded retries and ranged immutable downloads. SHA-256 of the whole archive and each allowlisted extracted file must match before activation. Expanded bytes and disk-space requirements are bounded. Installation stages files privately, preserves the previous directory and switches atomically. No model archive contains executable plugins. A new engine requires an APK update; additional compatible voice metadata has a catalog-backed UI.

VoicePackStore rehashes and reuses older prepared copies, retains partial downloads on cancellation, recovers interrupted directory switches and clears stale checking/removal states on restart. Removal waits for service shutdown and the shared native release queue, then removes only pack/transfer files. Settings, library and listening checkpoints remain. Native initialization independently verifies files again. Version directories match the existing engine fingerprints, so no audio-cache/checkpoint migration is needed for these unchanged weights.

More → Voice packs offers per-language/per-voice choice, authentic pre-download samples, progress, retry/resume and removal. Read aloud links to the same section when a model is missing. Downloads do not automatically start narration. Sample clips are original phrases generated by the exact voice at 1×, encoded as 64 kbps mono AAC/M4A and pinned by size/SHA-256. All ten Supertonic styles have English and Danish clips; Kokoro has Emma and Heart English clips. Samples use a small separate cache, exclusive audio focus and cancellation tickets, pause narration and retain its cursor/settings. Installed models also offer local previews at the selected rate. Temporary sample files are unique across rapid preview changes.

The immutable voice-packs-v1 release is marked prerelease and never latest, preserving the numeric stable app update feed. It includes licenses, provenance and validation. App publishing credentials never enter the Android APK or public sources.

## Reading and speech

The document-owned guided paint layer retains the prior full word range while resolving new Readium anchor helpers. Range and merged line rectangles change together in one animation frame; overlapping words retain one color/opacity including spaces. Pause retains the band; Stop clears it and cancels stale scheduled paints. Current-word locators/timing remain separate from visual coverage. All guided selectors include 300 WPM.

Speech UI, saved settings, service/IPC, backup validation, Kokoro native generation and presentation-clock bounds now accept 0.5–3×. Supertonic still synthesizes at 1×, applies pitch-preserving playback and reuses its waveform/source-sample checkpoint through rate changes. Kokoro preserves native speed generation and rate-specific cache identities. Readiness measures playable time at the requested playback rate; the existing PCM/lookahead bounds remain. A failed live speed change reports the unsupported route and restores the previous saved/actual speed. Android speech rates depend on its installed engine.

Tap the page counter to see cached readable word counts, before/remaining from the visible page, estimated WPM reading time, contents/chapter distribution and available page ranges. The compact statistics cache is keyed by book content, independent of typography. TOC fragments are resolved against parsed publication text. Nested entries are included within parents; top-level rows partition words. Page boundaries are sampled with a bounded budget in the existing pagination renderer and cached adjacent to the existing layout counts. Unknown ranges remain unavailable. Opening the sheet does not trigger a new full-book pagination generation or advance guided/listening cursors.

## Validation boundaries

Release validation records exact executed unit, Android and installation checks. Native synthetic tests verify full PCM submission/presentation, waveform identity, checkpoint persistence and queue ordering; they do not prove that a physical speaker sounds natural or that the Galaxy S10 sustains 3× indefinitely. Physical ARM performance, Bluetooth routes, intelligibility at 2.5/3×, battery and thermal behavior remain device acceptance checks. The core APK should remain far smaller than the earlier bundled build; prepared models still occupy private storage when retained or downloaded.
