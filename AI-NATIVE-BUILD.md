# Native AI speech source and rebuilding

Folio 0.7.0 uses unmodified official sherpa-onnx v1.13.8 Android JNI and ONNX Runtime 1.28.2 libraries. `bootstrap_ai.py` verifies the published Android archive SHA-256 before selecting only `libsherpa-onnx-jni.so` and `libonnxruntime.so` for arm64-v8a, armeabi-v7a, x86 and x86_64. The exact unmodified Kotlin Tts.kt is vendored under com.k2fsa.sherpa.onnx. All Folio integration changes are in the application source archive.

`Folio-native-source-0.7.0.zip` includes sherpa-onnx, ONNX Runtime, eSpeak NG, Piper phonemize, Kaldi decoder, Kaldi native fbank, KissFFT, simple-sentencepiece and JSON sources, with their upstream build scripts/licenses. `native-dependencies.json` records source URLs/checksums. The sherpa CMake files pin exact dependency revisions and hashes. This app does not modify those native sources. The Kokoro model is an independently licensed Apache-2.0 data artifact, restored by `bootstrap_ai.py`. Supertonic 3 weights by Supertone are independently licensed OpenRAIL-M; the Sherpa conversion uses MIT. `bootstrap_supertonic.py` restores the immutable INT8 package revision and records SHA-256 checksums in `app/src/main/assets/supertonic/artifacts.json`. Both weight licenses and attribution are included; the conversion LICENSE does not override the upstream weights license.

To rebuild the JNI libraries, unpack the native source archive on Linux/macOS with CMake, a C++ compiler and Android NDK installed. Set ANDROID_NDK to the NDK directory (use NDK r27 or newer for 16 KB support). In sherpa-onnx-1.13.8 run its `build-android-arm64-v8a.sh`, `build-android-armv7-eabi.sh`, `build-android-x86-64.sh` and `build-android-x86.sh` scripts. The scripts document optional SHERPA_ONNXRUNTIME_LIB_DIR/INCLUDE_DIR overrides and default to shared ONNX Runtime 1.28.2. They build the bundled CMake project with JNI and TTS enabled. Source dependency paths can be redirected in the existing CMake FetchContent declarations to the accompanying unmodified directories; otherwise the pinned downloads are verified by CMake. The upstream .github/workflows directory also contains the release build configuration.

ONNX Runtime's own `build.sh`/`tools/ci_build/build.py` and `cmake/deps.txt` are included for rebuilding that separately distributed MIT runtime. Its upstream Android build supports `--android --android_abi <ABI> --android_api 26 --android_ndk_path <NDK> --android_sdk_path <SDK> --build_shared_lib --config Release`; use the accompanying version's build help and dependencies for the full toolchain setup. Copy rebuilt runtime/JNI libraries into app/src/main/jniLibs/<ABI>/ and run the normal Folio Gradle build. Verify ELF load alignment and Android playback tests before distributing replacements.

Application and combined eSpeak phonemizer integration are supplied under GPL-3.0-or-later. Native and model components retain their individual licenses. Source archives contain no private signing keys, proprietary IVONA files or user ebooks. Keep the supplied source archives available alongside the APK when redistributing it.
