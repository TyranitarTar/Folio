# Folio 0.8.0

The reader now protects the screen for ten minutes after real input by default. Appearance offers Device timeout, 2/5/10/15/30-minute intervals, and Always. The monotonic input deadline survives rotation; automatic pagination and narration do not renew it. Guided reading keeps its visible page awake while running. Leaving the reader releases the window flag. Legacy explicit keep-awake preferences remain Always; Android decides when to sleep after protection expires.

Guided windows use a DOM Range between their actual anchored words. The range includes spaces and inline markup. Its painted rectangles merge per rendered line and page, using one color and opacity. Navigation retains the dominant word locator and bounding rectangle. Annotation and spoken-passage decoration groups remain separate.

Browse offers Sources, Downloads and Local. Exactly two built-in adapters support English and Danish: Project Gutenberg's official OPDS catalog and Wikisource's MediaWiki API. Gutenberg prefers illustrated EPUB 3, then EPUB, supported HTML or text. Wikisource follows an explicit contents list or the work's subpages, rejecting ambiguous/missing editions. Conversion preserves headings, paragraphs, notes, supported illustrations, rights notices and source/contributor links in a local EPUB. It does not infer or rewrite chapter titles. Unsupported resources fail visibly. The interactive export website is not automated.

A private SQLite queue and WorkManager jobs retain downloads across app/process restarts and wait for connectivity. Requests are paced across both adapters. Partial transfers use Range/If-Range only with a matching URL and strong ETag or last-modified marker. Unsupported resume restarts safely. Truncated responses remain partial; invalid ranges cannot commit. Transient failures retry with exponential backoff and provider Retry-After. Explicit cancellation retains partial input for retry and never commits an incomplete import. Clear finished releases transfer files while retaining library books.

Source identity is stored alongside library metadata and full backups. Duplicate imports retain existing positions and annotations, including when a previously local EPUB gains source attribution. Import validation and library commit remain transactional. APK updates still use public GitHub release metadata, checksum and installed-signature verification, followed by Android's installation confirmation.

Limits: 20 queued downloads; direct EPUB 200 MB; converted text 20 MB; 120 linked sections; 100 supported illustrations, 5 MB each/50 MB total. Normal WorkManager execution can be interrupted by Android; stable-version partial transfers resume on the next run. No DRM/PDF/MOBI conversion, arbitrary-webpage crawling, extension execution or new accounts are included. Catalog availability and jurisdictional rights remain provider-dependent. Gutenberg's announced 2027 catalog transition will require an adapter update.

Validation is recorded in the matching release validation JSON: JVM parsing/conversion/resume/cancellation/backup tests, lint, Android source downloads and rendering tests, existing reader/navigation regressions, signature/native-pack comparison and signed in-app upgrade checks. A physical Galaxy S10 remains necessary to evaluate manufacturer power behavior and ARM narration performance.

Native speech libraries and both bundled voice packs are unchanged from 0.7.1. WorkManager's resolved dependencies and notices are included in the runtime inventory and Licenses screen. Publishing credentials and the local signing key are excluded from application/source artifacts.
